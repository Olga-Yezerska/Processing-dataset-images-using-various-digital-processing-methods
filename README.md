# Processing Dataset Images Using Various Digital Processing Methods

## 📌 Overview

This project focuses on applying different **digital image processing techniques** to a dataset of images. The goal is to analyze, transform, and improve images using classical computer vision methods.

Digital image processing involves using algorithms to analyze and manipulate images for better interpretation and quality enhancement.

---

## Objectives

* Apply multiple image processing techniques
* Compare results of different methods
* Analyze the impact of transformations on image quality
* Work with datasets and automate processing

---

## Features

* Batch image processing (White balance, CLAHE, Dark channel proir, Sharpen filter, histogram equalization)
* Edge detection (Canny, Pruitt, Directional filter, Harris, FAST)
* Image transformations
* Result export to CSV / Excel
* Comparison with ground truth
* Metrics: MSE, PSNR, SSIM, FOM, AUC-ROC
